# AI 热点集成站

一个轻量静态网站，用于聚合展示 AI 热点信息（模型更新、工具发布、行业应用、学习资源）。

## 如何开始使用（给访客）

1. 打开首页后，先看顶部摘要，了解站点用途。
2. 在搜索框输入关键词（例如：`Agent`、`多模态`、`RAG`）快速过滤内容。
3. 点击分类按钮（模型更新 / 工具发布 / 行业应用 / 学习资源）只看对应热点。
4. 点击卡片底部“查看详情”跳转外部链接。
5. 若提示“没有匹配结果”，请更换关键词或切回“全部”。

## 本地运行（给开发者）

```bash
cd /workspace/test
python3 -m http.server 4173
```

浏览器访问：

- `http://127.0.0.1:4173`

## 文件说明

- `index.html`：页面结构与卡片模板。
- `styles.css`：页面视觉与响应式布局。
- `script.js`：热点数据、筛选与搜索逻辑。
